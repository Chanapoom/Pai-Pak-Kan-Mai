# ไปพักกันไหม (Pai Pak Kan Mai)

เว็บแผนที่สองภาษา (ไทย / อังกฤษ) ช่วยเลือกว่าวันนี้จะไปพักหรือออกกำลังกายที่ไหน ทั้งสวนสาธารณะ อุทยาน ศูนย์กีฬา และยิมทั่วไทย ใช้ฟรี ไม่ต้องสมัครสมาชิก

เว็บจริง: **https://pai-pak-kan-mai.pages.dev** · English: [README.md](README.md)

## ความสามารถ

- **แท็บแนะนำ:** เลือกที่ที่เหมาะกับช่วงเวลาตอนนี้ (เวลากรุงเทพฯ) และยังเปิดนานพอให้ไปทัน พร้อมเหตุผลสั้น ๆ เช่น "เปิดถึง 22:00 · เข้าฟรี · ใกล้ MRT"
- **ค้นหาและกรอง:** พิมพ์ชื่อสถานที่ เขต หรือสถานีรถไฟฟ้า เลือกกิจกรรม เลือกตำแหน่งปัจจุบันหรือจุดบนแผนที่พร้อมรัศมี เลือกจังหวัด เปิดอยู่ เข้าฟรี สิ่งอำนวยความสะดวก หรือวันเวลาที่จะไป
- **841 แห่งใน 62 จังหวัด:** กรุงเทพฯ ละเอียดที่สุด (สวนของ กทม. ครบ 48 แห่ง ศูนย์กีฬา กทม. และยิมเครือหลัก) ต่างจังหวัดส่วนใหญ่มาจาก OpenStreetMap
- **ไม่เดาข้อมูล:** เวลาเปิด ค่าเข้า และความหนาแน่นที่ไม่ทราบ หน้าเว็บจะบอกตรง ๆ ว่า "ยังไม่ยืนยัน" ข้อมูลทุกชิ้นมีลิงก์ที่มา
- **สองภาษา:** สลับไทย / อังกฤษได้ทั้งหน้า ชื่อสถานที่แสดงเฉพาะที่แหล่งข้อมูลให้ ไม่ถอดเสียงเอง
- **น้องน่องไม้:** มาสคอตต้นไม้ใส่รองเท้าผ้าใบ เดินเล่นบนแผนที่เอง มีกิจวัตรตามช่วงเวลา ลาก เขย่า หรือโยนได้ วางบนหมุดแล้วน้องจะอ่านชื่อสถานที่ ซ่อนได้จากลิงก์ท้ายแผงซ้าย
- **เข้าถึงได้:** ใช้แป้นพิมพ์และโปรแกรมอ่านหน้าจอได้ คอนทราสต์ตามมาตรฐาน WCAG AA และเคารพการตั้งค่าลดการเคลื่อนไหว

## รันและทดสอบ

```bash
npm start   # เปิดเว็บที่ http://127.0.0.1:4173
npm test    # รันเทสต์ทั้งหมด
```

ต้องใช้ Node.js 20 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## โครงสร้าง

- `dist/` คือตัวเว็บทั้งหมด เป็นไฟล์ static ไม่มีขั้นตอน build
- `dist/app.js` หน้าเว็บและแผนที่ · `dist/core.js` ค้นหา กรอง จัดอันดับ · `dist/hours.js` คำนวณเวลาเปิดตามเวลาไทย · `dist/i18n.js` ข้อความไทย / อังกฤษ · `dist/buddy.js` พฤติกรรมของน้องน่องไม้
- `dist/places.json` ข้อมูลสถานที่ · `dist/rail.json` เส้นทางและสถานีรถไฟฟ้า · `dist/provinces.json` ขอบเขตจังหวัด
- `tests/` เทสต์อัตโนมัติ

## อัปเดตข้อมูล

- แก้ `dist/places.json` โดยคง `id` เดิม เพื่อไม่ให้ลิงก์ที่แชร์ไปแล้วเสีย
- ใส่ลิงก์ที่มาของข้อเท็จจริงแต่ละอย่างใน `sources` และวันที่ตรวจใน `checkedAt`
- ข้อมูลที่ไม่ทราบให้ใช้ `null` ห้ามเดาเวลาเปิด ค่าเข้า จำนวนคน หรือสายรถ
- เวลาแบบหลายช่วงใช้ `schedule.week` (0 = อาทิตย์ ถึง 6 = เสาร์) วันปิดใช้ `[]` วันพิเศษใส่ใน `schedule.overrides`
- ภาพสถานที่อยู่ใน `dist/photos/` (`id.jpg` 960px และ `id-sm.jpg` 500px) ใช้เฉพาะภาพที่มีสัญญาอนุญาต CC0, CC BY หรือ CC BY-SA และใส่ผู้ถ่าย สัญญาอนุญาต และหน้าไฟล์ในช่อง `photo`
- รัน `npm test` ทุกครั้งก่อนเผยแพร่ เทสต์จะตรวจที่มา สัญญาอนุญาตภาพ และคำแปล

### ฟอร์มแนะนำสถานที่

ใส่อีเมลหรือลิงก์ฟอร์มที่ยินดีเปิดเผยสาธารณะใน `dist/config.json` ถ้าเว้นว่างทั้งคู่ ฟอร์มจะไม่แสดง

```json
{ "suggest": { "email": "", "formUrl": "https://..." } }
```

## ขึ้นเว็บจริง

- นำโฟลเดอร์ `dist/` ขึ้นโฮสต์ไฟล์ static ที่ใช้ HTTPS เช่น Cloudflare Pages (Build command: ว่าง, Output directory: `dist`)
- มีหน้า `404.html`, `robots.txt`, `site.webmanifest` และภาพตัวอย่างเวลาแชร์ลิงก์ `brand/og-image.jpg` พร้อมแล้ว
- เว็บอยู่บน Cloudflare Pages ทุกครั้งที่ push ขึ้น `main` เว็บจะอัปเดตเอง ถ้าย้ายไปโดเมนของตัวเอง ให้แก้ `og:url`, `og:image` และ `canonical` ใน `dist/index.html`
- แผนที่ฐานใช้ tile ของ OpenStreetMap เหมาะกับปริมาณผู้ใช้ไม่มาก ถ้าผู้ใช้เพิ่มมาก ให้เปลี่ยนไปใช้ผู้ให้บริการ tile ที่รองรับงานจริง ตาม[นโยบายของ OSM](https://operations.osmfoundation.org/policies/tiles/)

## สถิติผู้ใช้

ใช้ Cloudflare Web Analytics นับจำนวนผู้เข้าชมโดยไม่ใช้คุกกี้และไม่ระบุตัวตน เปิดใช้หลังขึ้น Cloudflare Pages: เข้าโปรเจกต์ใน Cloudflare → Metrics → Web Analytics → Enable แล้วดูจำนวนคนเข้าต่อวัน หน้าที่เปิด ประเทศ อุปกรณ์ และลิงก์ที่พามา ได้ในหน้าเดียวกัน หน้า "ความเป็นส่วนตัว" ในเว็บแจ้งเรื่องนี้แล้ว ถ้าย้ายไปโฮสต์อื่น ให้แก้ข้อความในหน้านั้นให้ตรง (`privacyHtmlTh` / `privacyHtmlEn` ใน `dist/app.js`)

## แหล่งข้อมูลและสัญญาอนุญาต
